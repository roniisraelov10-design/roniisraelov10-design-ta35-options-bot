👋 שלום! אם אתה כאן, אתה רוצה להעלות את המערכת לאוויר (לאינטרנט).

זה טוב! הנה בדיוק מה שצריך לעשות.

⏱️ זמן משוער: 15 דקות
💻 דרוש: מחשב עם גישה לאינטרנט בלבד

================================================================================
  שלב 1: עדכן GitHub (אתר לשיתוף קוד)
================================================================================

1) עבור ל-GitHub.com
2) כנס או הירשם (חינם)
3) לחץ [+] פינה משמאל עליון → "New repository"
4) שם: ta35-options-bot
5) בחר "Public" ✓
6) לחץ "Create repository"

👉 סיימת! עכשיו יש לך מקום בשרת GitHub שלך.

================================================================================
  שלב 2: העלה את הקבצים שלנו ל-GitHub
================================================================================

דרך 1 — עם Git (קצת יותר טכני):

  בTerminal / Command Prompt:
  
  cd ~/Desktop
  git clone https://github.com/[USERNAME]/ta35-options-bot.git
  cd ta35-options-bot
  
  (העתק את כל קבצי הפרויקט לתיקייה הזו)
  
  git add .
  git commit -m "First upload"
  git push origin main

דרך 2 — ללא Git (פשוט יותר):

  1) בGitHub, לחץ "Upload files"
  2) גרור את תיקיית הפרויקט כולה לחלון
  3) לחץ "Commit changes"

👉 סיימת! הקבצים כעת בשרת.

================================================================================
  שלב 3: הפעל ב-Streamlit Cloud (החלק הקל)
================================================================================

1) עבור ל-https://streamlit.io/cloud
2) לחץ "Sign up" (או התחבר עם GitHub)
3) אשר את ה-permissions ל-Streamlit
4) לחץ "New app"
5) בחר:
   - Repository: [USERNAME]/ta35-options-bot
   - Branch: main
   - Main file: dashboard/app.py
6) לחץ "Deploy"

⏳ המתן 2-3 דקות...

✅ סיים! קיבלת URL כמו:
   https://ta35-options-bot.streamlit.app

🎉 זהו! הדשבורד שלך חי ב-אינטרנט!

================================================================================
  שלב 4: בדוק שהכל עובד
================================================================================

בדפדפן, עבור ל-https://[your-url].streamlit.app

בדוק:
  ✅ האם טבלת אותות מופיעה?
  ✅ האם גרפים עובדים?
  ✅ האם אני יכול לבחור אות ולראות Payoff?

אם הכל עובד: 🎉 מברוק!

אם משהו לא עובד:
  - רענן את הדף (F5)
  - המתן 30 שניות ועדכן שוב
  - בדוק את Logs ב-Streamlit Cloud

================================================================================
  עדכונים עתידיים
================================================================================

כאשר תרצה לשנות משהו:

1) ערוך את הקובץ (למשל: app.py)
2) Save
3) בTerminal:
   git add .
   git commit -m "עדכון"
   git push origin main
4) Streamlit יעדכן אוטומטית! (תוך 1-2 דקות)

================================================================================
  שאלות נפוצות (FAQ)
================================================================================

Q: האם הדשבורד בחינם?
A: כן! Streamlit Community Cloud חינם לחלוטין.

Q: האם צריך כרטיס אשראי?
A: לא. כל דבר בחינם.

Q: כמה עולה לשמור נתונים?
A: בשלב 1 אנחנו לא שומרים — רק מציגים דוגמה.
   אם תרצה שמירה, צריך database (PostgreSQL/SQLite) — זה תשלום קטן.

Q: מה אם יש שגיאה?
A: בדוק את Logs ב-Streamlit Cloud:
   ספר לי מה השגיאה כדי שאוכל לעזור.

Q: האם אני יכול לחזור לגרסה קודמת?
A: כן, ב-GitHub אתה יכול לחזור ל-Commit ישן.

Q: האם זה בטוח?
A: כן. GitHub דומה ל-Dropbox אבל לקוד.
   Streamlit Cloud מהודקת ומוסמכת.
